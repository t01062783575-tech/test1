할일·일정·습관을 한 곳에서 관리하는 **개인용 플래너 캘린더**입니다.
여러 생산성 앱에서 자주 쓰는 기능을 한 화면에 모았어요.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

서버나 DB 없이 동작합니다. 모든 데이터는 브라우저 `localStorage`에 저장되고,
설정 → 데이터에서 JSON 백업 내보내기/불러오기를 할 수 있어요.

## 기능 (영감을 받은 앱)

| 기능 | 설명 | 참고한 앱 |
| --- | --- | --- |
| 자연어 빠른 추가 | `내일 오후 3시~5시 팀 회의 #업무 @업무 !1`, `매주 월요일 9시 주간 보고`, `3일 후 보고서 제출 !!` | Todoist, Fantastical |
| 월 · 주 · 일 캘린더 | 한국 공휴일·대체공휴일 표시, 현재 시각 표시선, 겹치는 일정 나란히 배치 | Google 캘린더 |
| 드래그 앤 드롭 | 캘린더 안에서 일정을 다른 날짜·시간으로 이동, 날짜 없는 할일을 캘린더로 끌어 시간 배정 | Sunsama, TickTick |
| 오늘 화면 | 지난 할일 한 번에 오늘로 옮기기, 진행률, 오늘의 습관, 다가오는 7일 | Things 3, Todoist |
| 할일 목록 | 수집함·오늘·7일·전체·완료, 카테고리/태그 필터, 정렬 | Todoist |
| 반복 | 매일·평일·매주·매월·매년, 간격, 종료일, 회차별 완료/삭제 | Google 캘린더 |
| 하위 할일 · 메모 · 우선순위 · 알림 | 우선순위 4단계 색상, 브라우저 알림 | Todoist, TickTick |
| 우선순위 매트릭스 | 중요도×긴급도 4분면, 끌어서 옮기면 우선순위·날짜 자동 변경 | TickTick (아이젠하워) |
| 뽀모도로 집중 타이머 | 할일과 연결, 집중 시간 기록 | TickTick, Forest |
| 습관 트래커 | 7일 체크, 연속 기록(🔥), 16주 잔디 | Streaks, Habitica |
| 통계 | 최근 14일 완료 수·집중 시간, 카테고리별 남은 할일 | TickTick |
| 검색 · 명령 팔레트 | `Ctrl/⌘ + K` | Linear, Notion |
| 키보드 단축키 | `N` 새 항목, `Q` 빠른 추가, `F` 타이머, `1~6` 화면 전환, `←/→`·`T`·`M/W/D` 캘린더 | Linear |
| 다크 모드 · 모바일 | 시스템 테마 연동, 모바일 하단 탭, 홈 화면에 추가(PWA 매니페스트) | |
| 내보내기 | JSON 백업, `.ics` 내보내기(구글/애플 캘린더로 가져오기) | |

### 빠른 추가 문법

- 날짜: `오늘`, `내일`, `모레`, `금요일`, `다음주 화요일`, `주말`, `3일 후`, `2주 뒤`, `12월 25일`, `12/25`, `25일`, `2026-10-01`
- 시간: `오후 3시`, `저녁 7시 반`, `15:30`, `3시~5시`, `10시 2시간`, `15:00 30분` (오전/오후 없이 1~7시는 오후로 인식)
- 반복: `매일`, `평일마다`, `매주 (월요일)`, `격주`, `매달 (15일)`, `매년`
- 우선순위: `!1` `!2` `!3` 또는 `!!!` `!!` `!`
- 태그: `#태그`, 카테고리: `@업무`

시간이 들어가면 일정, 없으면 할일로 만들어져요.

## 프로젝트 구조

- `src/app/page.tsx` — 진입점 (플래너를 클라이언트 전용으로 로드)
- `src/components/Planner.tsx` — 앱 셸: 사이드바, 모바일 탭, 단축키, 알림, 테마
- `src/components/views/` — 오늘 · 캘린더 · 할일 · 매트릭스 · 습관 · 통계 화면
- `src/components/ItemModal.tsx` — 할일/일정 편집 창
- `src/components/QuickAdd.tsx` — 자연어 빠른 추가 입력
- `src/lib/quickAdd.ts` — 자연어 파서
- `src/lib/recurrence.ts` — 반복 일정 계산
- `src/lib/holidays.ts` — 대한민국 공휴일 (음력 공휴일은 2025~2027년 수록)
- `src/lib/store.tsx` — 데이터 저장소 (localStorage)

## Deploy

Vercel에 별도 프로젝트로 배포할 때 Root Directory를 `personal-planner`로,
Ignored Build Step을 `bash scripts/vercel-ignore-build.sh`로 설정하세요.
환경 변수는 필요 없습니다.
